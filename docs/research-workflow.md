# 可复现研究流程

1. 固定数据来源、证券集合、观察期、执行时点、价格口径与规则版本。校验缺失、重复、停牌及公司行为。避免只选择当前存续证券产生生存者偏差。
2. 先按时间划分训练、验证、测试区间，再在训练集拟合任何标准化或特征转换。本项目的基础收益率/动量不拟合全局参数；PPO 的测试预热仅使用历史区间。
3. 在训练/验证集选择超参数、种子和成本设定，保留测试集作为最终未见区间。脚本的 80/20 留出是最低限度示例，复杂实验应增加独立验证段与滚动样本外检验。
4. 使用相同数据与成交假设比较动量、持有、空仓等基线；PPO 单次训练不会自动证明优于基线。报告多种子分布与交易频率、费用、回撤、敞口和成本敏感性。
5. 保存配置、数据哈希、代码提交、依赖版本、种子、checkpoint 和原始账本；基础 CLI 自动保存输入哈希、配置与 Python/包版本，训练入口另存 RL 依赖版本。正式实验另保存 `git rev-parse HEAD` 与 `python -m pip freeze`。
6. 使用离线 paper 账本复核信号日期与成交日期、现金和持仓变化。当前 paper 是历史回放，不是持续运行或可恢复的交易服务。

指标口径：总收益为期末权益/初始现金减一；最大回撤为从历史权益峰值到后续权益的最大跌幅；费用合计含佣金和卖出税费，滑点体现在成交价中。未实现年化指标，以免对合成工作日数据隐含真实年化日历假设。

任何真实市场结论都需要独立数据验证；合成数据运行、PPO smoke test 和工程测试只能证明相应程序路径可执行。
